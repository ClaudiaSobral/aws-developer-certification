# 0.0

## Objetivo do módulo:


- Descrever as seis fases do AWS Developer Learning Plan e os resultados esperados de cada uma delas.
- Configurar o ambiente de desenvolvimento local com o AWS CLI, o AWS SDK e o AWS Cloud Development Kit (AWS CDK) para criar aplicações em nuvem.
- Verificar se as credenciais e permissões da AWS estão configuradas corretamente para o trabalho de desenvolvimento
- Aplicar as práticas recomendadas de segurança ao configurar a conta da AWS para desenvolvimento, incluindo a autenticação multifator (MFA) e a configuração de usuário do AWS Identity and Access Management (AWS IAM)

## Resumo do módulo:

- Esse módulo introduz aos conceitos de desenvolvimento em nuvem AWS numa progressão semelhante ao mundo real
    - Algumas fases são operações CRUD (criação, leitura, atualização e exclusão) na prototipagem, adição progressiva de outros elementos, como armazenamento em cache, autenticação, monitoramento e automação.
    - Ele também demonstra um cenário prático hands-on: uso do comando de linha pelo AWS CLI para oprações, SDK para acesso programático e CDK para implantação de infraestrutura.

## As 6 fases
- Fase 1: Criar uma API
    - Criação de uma API de catálogo para loja online serverless. Contém principais serviços da AWS e operações CRUD (criação, leitura, atulização e exclusão)
    - Serviços: AWS Lambda, Amazon API Gateway e Amazon DynamoDB
    - Habilidades: arquitetura serverless, design de banco de dados NoSQL e desenvolvimento de API Rest
- Fase 2: Adicionar complexidade
    - Escala a API com otimização de desempenho, suporte de mídia e processamento assíncrono.
    - Serviços: Amazon S3, Amazon ElastiCache, Amazon CloudFront, Amazon Simple Queue Service (Amazon SQS), Amazon Simple Notification Service (Amazon SNS), Amazon EventBridge e Amazon Kinesis
    - Habilidades: estratégias de armazenamento em cache, configuração da rede de entrega de conteúdo (CDN), tratamento de upload de arquivos, padrões de mensagens, processamento de fluxos e otimização do Lambda
- Fase 3: Expandir o toolkit
    - Criação de aplicações tolerantes a falha usando contêineres, implantações EC2 e estratégias de integração.
    - Serviços: Amazon ECS, AWS Fargate, Amazon EC2 e Application Load Balancer
    - Habilidades: conteinerização, implantação do EC2, balanceamento de carga, padrões de resiliência, testes de integração e estratégias de simulação
- Fase 4: Segurança
    - Adiciona controles de segurança a nível corporativo.
    - Serviços: Amazon Cognito, AWS IAM, AWS Secrets Manager e AWS KMS
    - Habilidades: gerenciamento de identidade, criptografia e práticas recomendadas de segurança
- Fase 5: Infraestrutura e implantação
    - Automatização da implantação de infraestrutura com fluxos de trabalho profissionais. Uso de infraestrutura como código e pipelines de CI/CD.
    - Serviços: AWS CDK, AWS CodePipeline e AWS CloudFormation
    - Habilidades: infraestrutura como código, testes automatizados e estratégias de implantação
- Fase 6: Operações
    - Implanta monitoramento abrangente e excelência operacional. Criação de painéis, alertas e estratégias de otimização de desempenho.
    - Serviços: Amazon CloudWatch, AWS X-Ray e AWS Systems Manager
    - Habilidades: observabilidade, ajuste de desempenho e painéis operacionais
