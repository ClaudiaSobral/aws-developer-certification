# 0.0

## Objetivo do módulo:


- Descrever as seis fases do AWS Developer Learning Plan e os resultados esperados de cada uma delas.
- Configurar o ambiente de desenvolvimento local com o AWS CLI, o AWS SDK e o AWS Cloud Development Kit (AWS CDK) para criar aplicações em nuvem.
- Verificar se as credenciais e permissões da AWS estão configuradas corretamente para o trabalho de desenvolvimento
- Aplicar as práticas recomendadas de segurança ao configurar a conta da AWS para desenvolvimento, incluindo a autenticação multifator (MFA) e a configuração de usuário do AWS Identity and Access Management (AWS IAM)

## Resumo do módulo:

- Esse módulo introduz aos conceitos de desenvolvimento em nuvem AWS numa progressão semelhante ao mundo real
    - Algumas fases são operações CRUD (criação, leitura, atualização e exclusão) na prototipagem, adição progressiva de outros elementos, como armazenamento em cache, autenticação, monitoramento e automação.
    - Ele também demonstra um cenário prático hands-on: uso do comando de linha pelo AWS CLI para oprações, SDK para acesso programático e CDK para implantação de infraestrutura.
